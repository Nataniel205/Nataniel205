My name is Nataniel and I am a student of Chemical Engineering with Engineering Physics at Chalmers University of Technology with a particular interest in numerical methods, process simulation and scientific computing.

I enjoy using programming to solve problems related to chemical engineering, especially when they involve thermodynamics and process modelling. I am also interested in object-oriented programming and writing modular code that can be reused and extended, which is the design philosophy behind everything that I write.

## Selected projects 
The projects which you will find on this page are related to my studies and illustrate how programming can be used to solve problems in chemical engineering. Some of these are presented below.

### ```thermodynamics.py```

General purpose Python module for anything from adiabatic flashes using the Rachford-Rice equation with enthalpy balances to generic bubble-point calculations. Support for non-ideal models coming soon.

Topics:

```Python``` ```NumPy``` ```Thermodynamics``` ```Numerical Methods```

### ```DistillationColumn.py```

A steady-state distillation column simulator based on the MESH-equations (**M**aterial, **E**quilibrium, **S**ummation and **H**eat balances).

The project employs different techniques for handling particularly problematic distillations. 

Topics:

```Python``` ```NumPy``` ```Thermodynamics``` ```Numerical Methods``` ```Process Simulation```
